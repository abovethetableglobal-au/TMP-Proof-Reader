# TMP Check — Information Request for Way Too Go Traffic Management

**Status:** DRAFT — for Owner approval before sending.
**Purpose:** Understand how WTGTM prepares and checks TMPs today, so TMP Check is built around your real documents and requirements.

## How we will handle your documents
- Used only for developing and testing TMP Check for WTGTM.
- Anonymised copies preferred (client names, addresses, contacts and project numbers replaced). If you supply originals, we need your written permission first.
- Stored privately; not shared with third parties; not used to train public AI models.
- Deleted or returned on request.

9. What file formats do you send (Word, PDF, scanned)? What software produces your TGS drawings?

**What matters**

13. Which issues would you consider "must never miss"?
