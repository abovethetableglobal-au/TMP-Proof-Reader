## 4. What moves the value
| Raises value | Lowers value |
|---|---|
| Paying customers on monthly subscriptions (recurring revenue) | One customer = most of the revenue (concentration) |
| Several customers; written contracts | Owner runs every check (owner dependence) |
| Measured accuracy (benchmarks vs proofreader) and low complaint history | Dependence on one AI supplier (Anthropic) and its pricing |
| Clean books (Xero/MYOB), Stripe history | WA-only rule library; regulation changes (Code updates) |
| Rule libraries for other states | Liability exposure if a missed issue causes harm |
| Clear ownership of the code, brand and domain | Unclear IP position of AI-generated code (get legal advice) |
| Operations manual (SOPs) a buyer can follow | Easy for competitors to copy with AI tools |
