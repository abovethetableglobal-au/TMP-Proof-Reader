# TMP Check — Compliance Rule Review (WA)

**For:** Tara, Way to Go Traffic Management  
**Source:** Main Roads WA *Traffic Management for Works on Roads Code of Practice*, March 2026 (page numbers are the Code's printed page numbers)  
**Rules:** 22 (core set)

## What we are asking
TMP Check will use these rules to raise *potential issues* in TMPs. They are plain-language summaries, not the Code's wording. Please mark each rule:

- **Accept** — correct as written
- **Amend** — correct the requirement, when it applies, or the severity (add a comment)
- **Reject** — should not be checked (add a reason)

Also tell us about any requirement you regularly see TMPs get wrong that is **not** on this list.

Severity: **Critical** = potential serious safety or mandatory issue needing immediate attention · **Major** = significant compliance/completeness concern · **Moderate** = important inconsistency · **Minor** = editorial · **Query** = needs human confirmation.
